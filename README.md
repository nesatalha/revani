# Revani

Royal Enfield Hunter 350 için yuvarlak gidon ekranı.

- **Ekran:** Waveshare ESP32-S3 2.8" 480×480 yuvarlak kart (LVGL)
- **Mobil:** Flutter arayüz + Kotlin arka plan servisi (Android)
- **Bağlantı:** BLE
- **Önce:** Google Maps navigasyonu (dönüş oku, mesafe, harita)
- **Sonra:** OBD ile devir göstergesi
